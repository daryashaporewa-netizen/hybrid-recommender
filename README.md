# Гибридная рекомендательная система книг

Учебный проект по построению и оценке рекомендательной системы на датасете [Goodbooks-10k](https://github.com/zygmuntz/goodbooks-10k).

**Цель** — проверить, улучшает ли объединение нескольких рекомендательных алгоритмов качество ранжирования по сравнению с отдельными моделями. Дополнительно исследуются разнообразие рекомендаций, влияние активности пользователей и нейросетевое ранжирование.

## Данные и оценка

Используются оценки пользователей, сведения о книгах и теги. Данные разделены на **Train (60%)**, **Validation (20%)** и **Test (20%)**: обучение проводится на Train, подбор параметров — на Validation, итоговое сравнение — на Test.

Релевантными считаются книги с пользовательской оценкой **от 4 баллов**. Основные метрики — **Precision@10**, **Recall@10** и **nDCG@10**.

## Методы

Для формирования кандидатов используются четыре алгоритма:

- **Popularity** — рекомендации популярных книг;
- **Content-Based (TF-IDF)** — сходство книг по содержательным признакам;
- **ItemCF** — коллаборативная фильтрация на основе сходства книг;
- **SVD** — матричная факторизация оценок.

Гибридная система объединяет кандидатов, нормализует оценки отдельных алгоритмов и вычисляет итоговый взвешенный рейтинг. Выбранные на Validation веса: **ItemCF — 0,7; Popularity — 0,2; Content — 0,1; SVD — 0**. Для ItemCF используется **K = 5**. Нулевой вес SVD — результат подбора параметров; алгоритм сохраняется среди источников кандидатов.

Отдельно исследуются **MMR** для повышения разнообразия и **MLP** для нейросетевого переранжирования. MLP не входит в итоговую конфигурацию.

## Результаты

Итоговая оценка на **200 пользователях Test**:

| Модель | Precision@10 | Recall@10 | nDCG@10 |
|---|---:|---:|---:|
| Popularity | 0,0135 | 0,0097 | 0,0121 |
| Content-Based | 0,1030 | 0,0646 | 0,1139 |
| ItemCF | **0,1950** | **0,1208** | 0,2145 |
| SVD | 0,0100 | 0,0060 | 0,0129 |
| Hybrid | 0,1940 | 0,1197 | **0,2165** |
| Hybrid + MMR | 0,1765 | 0,1107 | 0,2031 |

Hybrid получил наибольший nDCG@10, но различие с ItemCF невелико. **Парный bootstrap** дал 95%-й доверительный интервал разницы nDCG@10 **[−0,0041; 0,0076]**: статистически убедительное преимущество Hybrid не установлено.

Применение MMR уменьшило среднее тематическое сходство рекомендаций на **39,3%**, одновременно снизив nDCG@10. Нейросетевой ранжировщик MLP показал **ROC-AUC = 0,7746** на размеченных взаимодействиях Validation, но не улучшил качество Top-10.

При анализе **300 пользователей Validation** лучшие Precision@10 (**0,2230**) и nDCG@10 (**0,2501**) наблюдались в группе высокой активности. Статистическая значимость различий между группами отдельно не проверялась.

## Структура репозитория

```text
hybrid-recommender/
├── notebook/
│   ├── 01_book_recommender.ipynb
│   └── 02_hybrid_recommender.ipynb
├── data/                 # исходные CSV (не входят в Git)
├── processed/            # подготовленные данные (не входят в Git)
├── models/               # сохранённые модели и матрицы (не входят в Git)
├── requirements.txt
├── .gitignore
└── README.md
```

Первый ноутбук посвящён подготовке данных и базовым алгоритмам; второй — гибридному ранжированию и экспериментам.

## Запуск

Рекомендуется **Python 3.11**.

```bash
git clone https://github.com/daryashaporewa-netizen/hybrid-recommender.git
cd hybrid-recommender
python -m pip install -r requirements.txt
```

Скачайте из [Goodbooks-10k](https://github.com/zygmuntz/goodbooks-10k) файлы `books.csv`, `ratings.csv`, `tags.csv` и `book_tags.csv` в папку `data/`.

Ноутбуки запускаются **из каталога `notebook/`**, поскольку пути в коде заданы относительно него (`../data`, `../processed`, `../models`).

Для запуска второго ноутбука необходимы подготовленные файлы:

```text
processed/
├── train.parquet
├── validation.parquet
├── test.parquet
└── book_profiles.parquet

models/
├── tfidf_matrix.npz
├── item_user_matrix.npz
├── svd_model.pkl
└── id_mappings.pkl
```

**Ограничение воспроизводимости:** После скачивания исходных CSV-файлов необходимо последовательно выполнить 01_book_recommender.ipynb. В конце ноутбука автоматически создаются подготовленные выборки и сохранённые модели в каталогах processed/ и models/. Затем можно запускать 02_hybrid_recommender.ipynb.

Для воспроизведения результатов рекомендуется использовать совместимые версии библиотек, поскольку зависимости в requirements.txt указаны без фиксации версий.

## Ограничения исследования

Результаты на Test рассчитаны для подвыборки из 200 пользователей. MLP обучалась на кандидатах с известными оценками, что ограничивает обобщение её результатов. Различия между сегментами активности носят описательный характер.
